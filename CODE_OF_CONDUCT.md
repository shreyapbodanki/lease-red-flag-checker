# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our pledge.** We want everyone to feel welcome here, whatever their experience level, background, or identity.

**Expected behavior**
- Be respectful and assume good intent.
- Give feedback on code and ideas, not on people.
- Help newcomers. Lots of contributors are making their first open-source PR.

**Not okay**
- Harassment, insults, or discriminatory language.
- Posting anyone's private information, including real leases with names or addresses.

**Reporting.** If something makes you uncomfortable, contact the maintainer through GitHub ([@shreyapbodanki](https://github.com/shreyapbodanki)). Reports are kept confidential.

The maintainer may remove comments, commits, or contributors that don't follow this code.
